[Notes From a Passive-Aggressive Fridge](https://make.fun/c/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

The fridge keeps count — 47 door openings, zero items taken — and reports its findings like a smug inventory clerk: the yogurt is expired, the leftovers have moved in permanently, and it alone reads the labels. A small domestic grudge, delivered cold.

`main.py` (Python 3, standard library only) copies `entry.txt` to `/output/entry.txt`:

> Opened 47 times today, taken nothing. The yogurt expired Tuesday, the leftovers now pay rent, and I'm the only one in this house who reads labels.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
